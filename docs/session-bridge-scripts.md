# 回をまたぐ「つなぎ台本」

> 回の冒頭と終了時に講師が読む「つなぎ台本」をまとめたものです。各回の講師が異なっても、参加者が回と回の内容のつながりを理解できるようにします。目的は2つあります。講師どうしの引き継ぎの手間を減らすことと、参加者が「前回やったことと今日やることの関係」を理解できるようにすることです。

## 使い方

- **冒頭の振り返り台本（A）** は、その回の講師が開始5分間で使います。前回の講師から引き継ぎがなくても、この台本を読めば、前回の内容との最低限のつながりを説明できます。
- **終了時の橋渡し台本（B）** は、その回の講師がクロージングの2〜3分で使います。次回の講師が誰であっても、参加者が「次に何を学ぶか」を知った状態で回を終えられるようにします。
- 台本中の「接続フレーズ」「次回への接続フレーズ」は、そのまま口に出して読める文言にしてあります。自分の言葉に変えても構いませんが、趣旨は保ってください。
